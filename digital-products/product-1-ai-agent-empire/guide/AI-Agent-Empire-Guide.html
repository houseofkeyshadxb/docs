Troubleshooting Guide

Common Issues

"API key not found"

# Verify your .env file exists and has the key
cat .env | grep ANTHROPIC
# Should output: ANTHROPIC_API_KEY=sk-ant-...

"Gmail authentication failed"

# Delete cached token and re-authenticate
rm gmail_token.json
python scripts/agent1_setup.py

"Agent generating wrong content"

Open the relevant CLAUDE.md and make instructions more specific. Add a "NEVER do X" section and concrete examples of desired output.

"Getting rate limited"

# Add to any script hitting limits
import time
time.sleep(1)  # 1-second delay between API calls
