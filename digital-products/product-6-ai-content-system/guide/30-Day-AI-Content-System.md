# MODULE 2: THE 30-DAY CONTENT CALENDAR

## Week 1 — Authority Building (Days 1–7)

### Day 1 — LinkedIn: Your Origin Story
**Prompt:**
```
Using my Brand Voice Document above, write a LinkedIn post about how I got into [YOUR FIELD].
Structure: Start with the moment everything changed. 2-3 paragraphs of story. End with a lesson and a question for the audience.
Length: 200-250 words. No hashtags until the end. No emojis in the body.
```

### Day 2 — Instagram: Before & After
**Prompt:**
```
Write an Instagram caption showing the transformation my clients/customers experience.
Structure: Describe "before" (their problem). Describe "after" (their result with my help). Make it visual and specific. End with CTA.
Tone: Warm and relatable. Length: 100-130 words. Include 5 relevant hashtags.
```

### Day 3 — Twitter/X Thread: Teach Something You Know Cold
**Prompt:**
```
Write a Twitter/X thread (8 tweets) teaching [ONE THING YOU KNOW DEEPLY].
Tweet 1: Hook — counterintuitive claim or shocking stat
Tweets 2-7: One lesson per tweet, each self-contained and under 270 chars
Tweet 8: Summary + CTA linking to [YOUR PRODUCT/SERVICE]
Make every tweet able to stand alone. No filler.
```

### Day 4 — LinkedIn: The Mistake Post
**Prompt:**
```
Write a LinkedIn post about the biggest mistake [YOUR AUDIENCE] makes with [YOUR TOPIC].
Structure: State the mistake clearly. Explain WHY people make it. Give the correct approach. End with a question.
Don't make me look superior — make the mistake feel relatable and human.
Length: 180-220 words.
```

### Day 5 — Instagram: Tool/Resource Recommendation
**Prompt:**
```
Write an Instagram post recommending [A TOOL OR RESOURCE] I genuinely use.
Structure: Name the tool. What it does. Best specific use case. Cost. My honest take (include a small con for credibility). Rating.
Length: 80-100 words + 5 hashtags. Conversational, not promotional.
```

### Day 6 — LinkedIn: Data/Stats Post
**Prompt:**
```
Find 3 surprising statistics about [YOUR INDUSTRY/TOPIC] and build a LinkedIn post around them.
Structure: Open with the most shocking stat. Context for each one. What this means for [AUDIENCE]. Actionable takeaway.
Cite sources generally (e.g., "per recent industry data") rather than specific links.
Length: 200-250 words.
```

### Day 7 — Twitter/X: Quick Tips Thread
**Prompt:**
```
Write 7 quick tips about [YOUR TOPIC] as a Twitter thread.
Format: Tweet 1 = hook ("7 things about [X] that took me [Y] to learn")
Tweets 2-8 = one tip per tweet, numbered, actionable, under 240 chars each
Last tweet = link to your [PRODUCT/NEWSLETTER/PROFILE]
Keep it punchy. No fluff.
```

## Week 2 — Social Proof & Results (Days 8–14)

### Day 8 — LinkedIn: Case Study
**Prompt:**
```
Write a LinkedIn case study post about a client or customer result.
Use this format: Situation (their problem). Complication (why it was hard). Resolution (what we did). Result (specific numbers if possible).
If I don't have client results yet, write it about my own results.
End with: what this means for others in the same situation.
Length: 220-260 words. Use line breaks between sections.
```

### Day 9 — Instagram: Carousel Content Plan
**Prompt:**
```
Write the text for a 7-slide Instagram carousel about [TOPIC].
Slide 1: Hook (big promise or bold claim)
Slides 2-6: One insight per slide (short, punchy, under 15 words each)
Slide 7: Summary + follow/save CTA
Make each slide worth reading on its own. Include suggested visual description for each slide.
```

### Day 10 — Twitter/X: Controversial Take
**Prompt:**
```
Write a Twitter thread where I defend a contrarian position about [YOUR INDUSTRY].
Position: [YOUR UNPOPULAR OPINION]
Thread structure:
- Tweet 1: State the controversial take directly
- Tweets 2-5: Build the argument (one point per tweet)
- Tweet 6: Acknowledge the strongest counterargument fairly
- Tweet 7: Restate my position with added nuance
- Tweet 8: Ask the audience what they think
Keep it confident but not arrogant.
```

### Day 11 — LinkedIn: Lessons Learned Post
**Prompt:**
```
Write a "lessons learned" LinkedIn post after [TIME PERIOD] of running [YOUR BUSINESS/CAREER].
Structure: Brief intro (not self-congratulatory). 5 numbered lessons — each 2-3 sentences. Closing that's honest about what's still hard.
Tone: Reflective, honest, teachable. Not a humble brag. Under 300 words.
```

### Day 12 — Instagram: "Day in the Life" Post
**Prompt:**
```
Write an Instagram caption showing a day in my life as [YOUR ROLE].
Make it specific and real — mention specific tools, times, tasks.
Show both the good and the less glamorous parts.
End with something that invites people to relate or share.
Length: 100-150 words. Casual, human tone.
```

### Day 13 — LinkedIn: The Value Post (Sell Without Selling)
**Prompt:**
```
Write a LinkedIn post that delivers so much value that readers naturally want to know more about [MY PRODUCT/SERVICE].
Topic: [SPECIFIC THING YOUR PRODUCT HELPS WITH]
Structure: Open with the problem. Give a complete, actionable solution (5-7 steps). At the end, mention — in one sentence — that I've packaged this into [PRODUCT NAME] for those who want it done for them.
Don't sell. Just teach. Length: 250-300 words.
```

### Day 14 — Twitter/X: Week in Review
**Prompt:**
```
Write a Twitter thread recapping what I worked on, learned, or observed this week.
Include: 1 thing that worked, 1 thing that didn't, 1 resource I discovered, 1 insight from a client or customer.
Keep each tweet conversational, honest, and specific — not generic.
End with a question about what others learned this week.
```

## Week 3 — Audience Growth (Days 15–21)

### Day 15 — LinkedIn: The "How I" Post
**Prompt:**
```
Write a LinkedIn post titled "How I [ACHIEVED RESULT] without [EXPECTED METHOD]"
Make the approach surprising. Break it into 5 steps.
Be specific — mention real tools, timelines, mistakes.
End: "If you want the full system, it's in [PRODUCT NAME]. Link in comments."
Length: 220-250 words.
```

### Day 16 — Instagram: Quote Graphic Copy
**Prompt:**
```
Write 5 short, quotable statements about [YOUR TOPIC] that would work as Instagram quote graphics.
Each should: be under 15 words, be original (not a famous quote), spark thought or emotion, be attributable to me.
Format: "Quote" — [Your Name]
Pick your favourite and write a 50-word caption to go with it.
```

### Day 17 — Twitter/X: Question Thread
**Prompt:**
```
Write a Twitter thread of 8 questions that force [MY AUDIENCE] to think differently about [THEIR PROBLEM].
Tweet 1: Frame why these questions matter
Tweets 2-8: One hard question per tweet, each with brief context
Last tweet: Invite them to answer one in the replies
The questions should be uncomfortable but fair.
```

### Day 18 — LinkedIn: Industry Prediction
**Prompt:**
```
Write a LinkedIn post sharing 3 predictions about [YOUR INDUSTRY] in the next 12-18 months.
For each prediction: State it confidently. Give your reasoning (2 sentences). Say what you're personally doing because of it.
End: Ask readers which prediction they agree or disagree with most.
Length: 220-260 words. Own the predictions — don't hedge everything.
```

### Day 19 — Instagram: "What I Wish I Knew" Post
**Prompt:**
```
Write an Instagram caption: "What I wish someone told me when I started [YOUR BUSINESS/CAREER]"
Format: 5 short lessons (1-2 lines each), honest and direct.
Open with the most important one. End with something hopeful.
Length: 100-140 words. Relatable, no ego.
```

### Day 20 — LinkedIn: The FAQ Post
**Prompt:**
```
Write a LinkedIn post answering the 5 questions I get asked most often about [YOUR TOPIC].
Format: Each question bolded. Answer in 2-4 sentences. Conversational.
End: "What did I miss? Drop your question below."
Length: 250-300 words. This one should be highly saved and shared.
```

### Day 21 — Twitter/X: Resource Drop
**Prompt:**
```
Write a Twitter thread: "10 resources about [TOPIC] that I actually use (not just bookmarked)"
Tweet 1: Hook — "Sharing 10 [X] resources I've paid for, tested, or used weekly"
Tweets 2-11: One resource per tweet — name, what it does, cost, why I recommend it
Tweet 12: Ask followers to share their favourite
Keep each resource tweet under 240 chars.
```

## Week 4 — Conversion (Days 22–30)

### Day 22 — LinkedIn: The Problem-Agitate-Solve Post
**Prompt:**
```
Write a LinkedIn post using PAS formula about [YOUR AUDIENCE'S MAIN PROBLEM].
Problem: Name it specifically (not vaguely).
Agitate: Make the cost of the problem real — time, money, opportunity, emotion.
Solve: Present [YOUR PRODUCT/SERVICE] as the specific solution.
Tone: Empathetic, not fear-mongering. Length: 200-240 words.
```

### Day 23 — Instagram: Testimonial/Review Post
**Prompt:**
```
Write an Instagram caption to accompany a customer testimonial or result screenshot.
Structure: The result (lead with the outcome). Brief context (who, what problem). The solution. CTA to get the same result.
Avoid: Sounding like an ad. Make it feel like sharing a win, not selling.
Length: 80-100 words + 5 hashtags.
```

### Day 24 — Twitter/X: The Pitch Thread
**Prompt:**
```
Write a Twitter thread that sells [MY PRODUCT] without feeling salesy.
Thread structure:
- Tweet 1: Open with the result/transformation the product delivers
- Tweets 2-4: The problem it solves (story or data)
- Tweets 5-6: How it works (brief)
- Tweet 7: Who it's for (be specific)
- Tweet 8: Testimonial or result
- Tweet 9: Price + link + limited reason to act now
- Tweet 10: "Any questions? Reply below"
Make it feel like sharing something valuable, not a sales pitch.
```

### Days 25–30 — Repurposing Sprint
**Prompt for each day:**
```
Take my top 3 performing posts from this month (paste them below).
Repurpose them for [PLATFORM]:
- LinkedIn post → Twitter thread
- Twitter thread → LinkedIn carousel outline
- Instagram post → Email newsletter section
- Blog section → 5 social posts
Rewrite for the new platform's format and audience expectations, not just copy-paste.
[PASTE YOUR TOP POSTS]
```

# MODULE 3: THE 4 NEWSLETTERS

## Newsletter 1: Welcome Issue
**Prompt:**
```
Write a welcome newsletter for new subscribers to [YOUR NEWSLETTER NAME].
Structure:
- Warm opening (who you are, why they should be excited)
- What they'll get every week (specific, not vague)
- One piece of your best free content to earn trust immediately
- A question to reply to (this trains engagement)
- Sign-off with a human touch

Tone: [YOUR TONE]. Length: 350-450 words. No filler.
```

## Newsletter 2: Value-Heavy Edition
**Prompt:**
```
Write a weekly newsletter on the topic: [TOPIC].
Structure:
- Hook (1 paragraph — counterintuitive or timely)
- Main insight (3-5 paragraphs — teach one thing deeply)
- Practical application (numbered steps)
- Tool or resource recommendation (1-2 sentences)
- Closing thought (1 paragraph — leave them with something to think about)
- CTA (soft mention of your product or next action)

Length: 400-600 words. Dense with value, easy to scan.
```

## Newsletter 3: Story Edition
**Prompt:**
```
Write a newsletter issue that tells a personal story and extracts a business lesson.
Story idea: [DESCRIBE A REAL EXPERIENCE — even a small moment works]
Structure:
- Open in the middle of the story (in medias res)
- Build to the tension or turning point
- Reveal the lesson
- Apply it to your reader's situation
- End with a question or reflection

Length: 350-500 words. First person. No bullet points — this one is all prose.
```

## Newsletter 4: Product-Focused Issue
**Prompt:**
```
Write a newsletter issue that naturally leads to a mention of [MY PRODUCT].
The topic: [TOPIC THAT YOUR PRODUCT SOLVES]
Structure:
- Start with the problem (not your product)
- Give genuinely useful content addressing part of the problem
- At the transition: "If you want the full system, I built [PRODUCT]"
- Brief product description (3 sentences max)
- Link + price
- Return to close the newsletter with a non-promotional thought

Length: 350-450 words. The product mention should feel earned, not jammed in.
```

# MODULE 4: THE 4 BLOG POST FRAMEWORKS

## Blog Post 1: The Ultimate Guide
**Prompt:**
```
Write a 1,400-word blog post titled: "The Ultimate Guide to [YOUR TOPIC] for [YOUR AUDIENCE] in [CURRENT YEAR]"
Structure:
- Introduction (150 words — hook + what they'll learn)
- Section 1: What is [TOPIC] and why it matters (200 words)
- Section 2: The biggest mistake most people make (200 words)
- Section 3: The step-by-step system (600 words, numbered steps)
- Section 4: Tools and resources (150 words)
- Conclusion + CTA (100 words)

SEO: Use the keyword "[YOUR KEYWORD]" in the H1, first paragraph, 2 subheadings, and conclusion.
Tone: [YOUR TONE]. Include 1 internal link placeholder: "[LINK TO YOUR PRODUCT]"
```

## Blog Post 2: The Listicle
**Prompt:**
```
Write a 1,200-word blog post: "[NUMBER] Ways to [ACHIEVE RESULT] Using [YOUR METHOD/TOOL]"
Structure: Brief intro (100 words). [NUMBER] numbered items (80-100 words each). Conclusion with CTA.
Make each item genuinely actionable — include a mini-example or use case.
SEO keyword: [YOUR KEYWORD]. Title alternatives: provide 3 options.
```

## Blog Post 3: The Case Study
**Prompt:**
```
Write a 1,000-word blog post documenting a client result or my own result.
Structure:
- Headline (include a specific result metric)
- The situation before (200 words)
- The challenge (150 words)
- The solution/approach (300 words)
- The results (150 words — specific numbers)
- Key takeaways (150 words — 3 lessons)
- CTA to your product/service (50 words)

Make it honest — include what was hard or didn't work.
```

## Blog Post 4: The Opinion Piece
**Prompt:**
```
Write a 900-word opinion piece: "Why [CONTROVERSIAL POSITION ABOUT YOUR INDUSTRY]"
Structure:
- Open with the thesis statement (don't bury the lead)
- Acknowledge the mainstream view (fair representation)
- Your counter-argument (3 points)
- Evidence or reasoning for your position
- What this means practically for your reader
- Conclusion with your final stance

Be direct and opinionated. This should feel like someone saying something people think but don't say.
```
