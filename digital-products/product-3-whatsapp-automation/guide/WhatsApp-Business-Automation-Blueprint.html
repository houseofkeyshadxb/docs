Part 1: Platform Setup

⚙️
WhatsApp Business API Setup (Hours 1–3)
Two paths: Cloud (easiest) or Self-hosted (cheapest long-term)
1
Option A: Cloud API (Recommended for Beginners)
Sign up at business.facebook.com → Create a Meta Business Account → Add WhatsApp → Get your phone number verified. First 1,000 conversations/month are FREE.
2
Option B: Self-Hosted (n8n + WhatsApp)
Deploy n8n on Railway.app or Hetzner VPS ($5–10/month). Connect WA Business API. Gives you full control and lower costs at scale.
n8n setup command: npx n8n # Then connect: Credentials → WhatsApp Business Cloud API # Add your Phone Number ID and Access Token
3
Create Your Business Profile
Set: Business name, description (Arabic + English), address, email, website. Upload profile photo (400×400px). Set business hours and away message template.

Part 3: Bilingual Messaging (Arabic + English)

🌍
Language Detection & Routing
Serve UAE clients in their preferred language automatically
1
Detect Language on First Message
Use Claude API to detect if message is Arabic or English. Store preference in your CRM. Route all future messages in detected language automatically.
n8n HTTP Request to Claude: { "model": "claude-haiku-4-5", "messages": [{ "role": "user", "content": "Detect language (respond: AR or EN only): {{trigger.message}}" }] }
2
Bilingual Template Messages
All WhatsApp template messages must be pre-approved. Submit both Arabic and English versions. Arabic messages must use RTL formatting and proper Gulf dialect.
